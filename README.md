# Full-stack Option Analytic App: #

1. Collects and organizes cryptocurrency option market data into an interactive analytics platform.
2. Provides a structured view of option chains, contract information, and market statistics.
3. Integrates quantitative pricing models to compare theoretical valuations with market prices.
4. Visualizes implied volatility across different strikes and expiries to reveal market structure.
5. Enables interactive scenario analysis by evaluating how model inputs affect option pricing and risk.
6. Supports historical exploration of option contracts to study price, volatility, and Greek dynamics.
7. Accelerate data access through in-memory caching and session management for responsive user interactions.
